Volume Operator
---------------
Check the operator came up and elected a leader:

  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "proxmox-csi-plugin.fullname" . }}-operator
  kubectl -n {{ .Release.Namespace }} get lease {{ include "proxmox-csi-plugin.fullname" . }}-operator 2>/dev/null || true
  kubectl get pxstore

The last command should list one entry per Proxmox region/zone/storage, with
capacity matching `pvesm status` on the hypervisor. If it is empty, the operator
is either not leader yet or cannot reach Proxmox:

  kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "proxmox-csi-plugin.fullname" . }}-operator

CRDs
----
CRDs are rendered from files/crds/*.yaml with helm.sh/resource-policy: keep, so
`helm uninstall` leaves the volume ownership ledger in place. After bumping this
chart, CRDs already in the cluster are not automatically upgraded; apply by hand
if needed.
